# SnapReport — Incident Report Manager

A professional civic incident platform — report hazards, co-sign neighborhood
issues, and track municipal repairs end-to-end with before/after photo proof.

## Design System

Built on the **Superhuman — golden hour editorial** theme:

- **Canvas** — warm parchment `#f2f0eb`, ink charcoal `#292827` text
- **Brand** — midnight wine `#421d24` actions, royal violet `#714cb6` links,
  lilac mist `#d4c7ff` secondary surfaces
- **Typography** — Inter (Super Sans VF substitute), signature weight 460 at
  display sizes with tight tracking
- **Depth** — layering + backdrop blur, no drop shadows on UI surfaces

### Features

- Full-bleed golden-hour hero with floating glass product cards
- Trust logo strip, suite tab strip, dark feature band, gradient banner, wine footer
- Interactive city map with real coordinates → pins, drag-to-pan, scroll/button
  zoom, status layer toggles, hover tooltips, detail popovers, fit/reset views
- Report form with photo upload, tags, voice notes, categories, priority, ETA
- Solution threads with helpful/unhelpful ratings, share (WhatsApp/Email/Copy),
  repair progress tracker, live dispatch ticker, notification bell, dark mode

## Getting Started

```bash
cd project
npm install
npm run dev      # local dev server
npm run build    # production build
npm run preview  # preview the production build
npm run lint     # eslint
```
